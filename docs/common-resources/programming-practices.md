# Programming Best Practices

Despite being an Electrical Engineering club, most of our projects involve programming of some sort. As such it is valuable to learn how to write high-quality, readable code.

## General Advice

- [CodeAesthetic](https://www.youtube.com/@CodeAesthetic/videos) - Youtube channel with great videos on writing clean, readable code.

## C/C++

- [learncpp](https://www.learncpp.com/) - Text-based introduction to C++
- [The Cherno C++ Playlist](https://youtube.com/playlist?list=PLlrATfBNZ98dudnM48yfGUldqGD0S4FFb&si=pLsf1zulFX3jKtrf) - Video-based introduction to C++
- [Low Level NASA Coding Video](https://www.youtube.com/watch?v=GWYhtksrmhE) - Video on best practices for embedded systems programming in C
